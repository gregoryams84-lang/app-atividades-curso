Preparando seu computador pra usar IA de verdade

O que você leva desta aula: montar o ambiente de trabalho completo — Windows 11 Pro, Claude Pro, GitHub e VS Code conectados — e saber pra que serve cada peça.

Antes de qualquer coisa

Os 3 agentes da Aula 1 não nascem prontos — quem constrói é o Claude Code, rodando dentro do seu computador. Antes de escrever o primeiro comando, tem 4 peças que precisam estar no lugar: o sistema certo, o Claude no plano certo, uma conta que guarda seu projeto na nuvem, e o programa onde tudo isso se conecta.

Esse material é o passo a passo dessa montagem, na ordem exata em que ela precisa acontecer. Pula um passo e o próximo trava.

As 4 peças do seu ambiente

1

Windows 11 Pro

Confira em Configurações → Sistema → Ativação. Só o Windows 11 Pro tem as ferramentas necessárias pro Claude Code funcionar — o Home não serve.

Não tem o Pro? Dá pra adquirir a licença em lugares como o Mercado Livre, com preço pra todos os bolsos.

2

Claude, no plano Pro

Baixe em claude.com/download, instale no computador (não só na versão web) e crie sua conta, por e-mail ou Google. Na hora de escolher o plano, entre direto no Pro.

No plano gratuito o Claude Code não funciona — esse projeto é pra sair do papel de verdade, não pra testar.

3

Conta no GitHub

Crie sua conta gratuita em github.com. É a nuvem que registra todo o seu projeto numa linha do tempo — tudo que o Claude for fazendo fica salvo lá.

É esse cadastro que permite o Claude conectar e registrar o trabalho na nuvem.

4

VS Code, conectado ao GitHub

Baixe em code.visualstudio.com, instale e, na primeira abertura, faça login com a conta do GitHub que você acabou de criar. É essa a sua plataforma de trabalho.

GitHub (a nuvem) + Claude (a IA) + VS Code (onde tudo acontece) — as três pontas já conectadas.

Cada peça depende da anterior — por isso a ordem importa: sem o Pro do Windows, o Claude Code não roda; sem o GitHub, o VS Code não tem onde guardar o projeto.

Como tudo se conecta

Siga essa ordem — cada passo depende do anterior estar pronto.

Os dois modos, lado a lado

Modo 1 — Chat

Chat do Claude

  • Tira dúvidas e ajuda a escrever o prompt certo
  • Aceita texto ou áudio, se ajeita com o que você escreve errado
  • Não mexe direto nos arquivos do projeto

Use em paralelo, numa janela ao lado, pra pensar antes de agir.

Modo 2 — Code

Claude Code

  • Instalado como extensão dentro do VS Code (Ctrl+Shift+X, busca "Claude")
  • Trabalha direto nos arquivos e no código do seu projeto
  • Pede autorização de acesso Anthropic na primeira vez

É quem efetivamente escreve e ajusta o código pra você.

Uma peça que passa despercebida: o PowerShell

O PowerShell é o terminal do seu computador. Você não precisa abrir ele sozinho, mas é bom saber que ele existe: é ali que ficam guardadas as chaves e senhas de acesso (as chamadas APIs) que não podem circular pela nuvem — só o seu computador tem acesso.

Você nem precisa sair do VS Code pra usar: na parte de baixo da tela tem um painel de Terminal — é o mesmo PowerShell, no mesmo lugar onde você já fala com o chat e com o Code.

Sua vez

Confirma que seu ambiente está pronto. Ao lado de cada item, escreve com suas palavras que já foi feito (ex: "feito, plano Pro ativo"):

1Windows 11 Pro
2Claude, plano Pro
3Conta no GitHub
4VS Code conectado ao GitHub
Resumo rápido
  • Windows 11 Pro: verificado em Configurações → Sistema → Ativação.
  • Claude: instalado no computador, plano Pro — é o Pro que libera o Claude Code.
  • GitHub: conta criada — é a nuvem que registra o projeto.
  • VS Code: instalado e conectado à conta do GitHub — sua plataforma de trabalho.
  • Claude Code: instalado como extensão no VS Code, trabalhando junto com o chat.
  • PowerShell: o terminal do computador, onde ficam guardadas chaves e senhas.
