MCPs e Skills: o Claude com superpoderes

O que você leva desta aula: entender a diferença entre MCP e Skill, reconhecer as ferramentas dos três kits apresentados, cadastrar as contas necessárias e instalar tudo no VS Code — pronto pra colocar a mão na massa num projeto real do seu negócio.

Antes de qualquer ferramenta: dê contexto

Antes de pedir qualquer coisa pro Claude, antecipe quem você é. Não chegue perguntando direto — conte primeiro o essencial do seu negócio: o que você vende, quantos funcionários tem, onde fica, os números que importam. Só depois faça o pedido.

Exemplo real da aula: "Sou dono de uma pizzaria, tenho dois funcionários, fico no bairro X de São Paulo, entrego uma média de 30 pizzas no fim de semana e 10 durante a semana. Elabore uma estratégia de marketing pro Instagram e Facebook." Sem esse contexto antes, a resposta sai genérica — com ele, o Claude usa cada detalhe que você deu.

MCP e Skill, lado a lado

MCP

Abre uma porta nova

  • Dá acesso a algo que o Claude não consegue sozinho
  • Ex: buscar na internet, gerar imagem, conectar num banco de dados
  • Sem instalar, esse poder simplesmente não existe

Você instala, e uma porta nova se abre.

Skill

Ensina o melhor caminho

  • Não dá ferramenta nova, dá um manual de procedimento
  • Roteiro que o Claude segue quando a tarefa combina com o assunto
  • Ex: estruturar um post — gancho, desenvolvimento, chamada final

Ensina o melhor jeito de andar pela casa que já existe.

Não existe o modelo perfeito — existe o motor certo pra cada trabalho. Três produtos (Claude, Claude Code, Claude Cowork), duas formas de estender (Skill, MCP), quatro motores.

Os três kits de ferramentas

A

MCPs de pesquisa e automação

  • Context7 — documentação técnica atualizada, direto na fonte
  • Jina AI — busca e leitura real da web
  • Chrome DevTools — controla um Chrome de verdade
  • Supabase — banco de dados e back-end completo

Um MCP pode ser global ou só de um projeto. Se ele não aparece numa pasta diferente, não é bug — é escopo.

B

MCPs de mídia gerada

  • Kairogen — catálogo grande de imagem, vídeo e voz
  • Nanobanana — geração e edição de imagem via Gemini, direto
  • Magnific — upscaling e acabamento fino, o único remoto do kit

Kairogen quando não sabe qual modelo escolher. Nanobanana quando já sabe. Magnific pra dar o acabamento final.

C

Skills, CLI e referência

  • Superpowers — metodologia de trabalho (TDD, brainstorming, planos)
  • Find Skills — descoberta de skills prontas da comunidade
  • Hyperframes — produção de vídeo real a partir de HTML/CSS
  • Claude Cookbook — exemplos oficiais de código, pra programar contra a API

Nenhuma ferramenta deste kit é MCP — nenhuma abre porta nova.

Do cadastro à mão na massa

Duas ferramentas pedem chave própria (NanoBanana e Find Skills) — cole no VS Code antes de dar Start nelas.

Checklist de cadastro

  • Kairogen, Jina, Magnific e HeyGen — acesso via Google
  • Google AI Studio (NanoBanana) — API Key criada e guardada
  • Node.js instalado (nodejs.org, versão Windows)
  • Find Skills MCP — chave criada em Documentos → API
  • Supabase — inscrição via GitHub, organização e projeto criados
Mão na massa: o que muda na prática

A aula fecha com uma demonstração real de criação de site, do zero, dentro do VS Code. Alguns pontos valem pra qualquer projeto que você for tocar depois:

  • Modo automático: deixe o Claude Code no modo "auto", não manual — ele resolve sozinho o que puder e só te chama quando a decisão é sua.
  • Esforço proporcional: tarefa estrutural, feita uma vez (um site inteiro), vale deixar o Claude trabalhar mais forte. Pedido simples do dia a dia não precisa desse nível.
  • Nunca invente uma história falsa pro seu negócio — se não tem uma real, não conta nenhuma.
  • Uma conversa por projeto — site, Instagram, WhatsApp, cada um na sua conversa, pra não misturar informação.
  • Iteração é normal: aponte o que quer mudar (pode até colar um print) e peça o ajuste.

Resumo rápido
  • Contexto primeiro: conte quem você é pro Claude antes de pedir qualquer coisa.
  • MCP: abre uma porta nova — dá acesso a algo que o Claude não tem sozinho.
  • Skill: ensina um procedimento — não abre porta nenhuma.
  • Kit A: pesquisa e automação — Context7, Jina, Chrome DevTools, Supabase.
  • Kit B: mídia gerada — Kairogen, Nanobanana, Magnific.
  • Kit C: Superpowers, Find Skills, Hyperframes, Claude Cookbook.
  • Instalação: cole o mcp.json em Open User Configuration, Start em cada um, e não esqueça o Ctrl+S.
